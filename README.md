# Detector de Sismos

Hay **una sola versión** de esta app. La pública y la de este PC son el mismo código (`main`).

| Dónde | Enlace |
| --- | --- |
| Pública | https://gerard120464.github.io/detector-de-sismos/ |
| Este PC | http://127.0.0.1:5173/detector-de-sismos/ |

GitHub Pages es HTTPS y el ESP32 es HTTP: el navegador bloquea esa mezcla. Para unirte a **SISMOS-01**, enviar SSID/clave y ver la gráfica en vivo, usa el enlace de este PC.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

GitHub Pages se actualiza al hacer push a `main`.
